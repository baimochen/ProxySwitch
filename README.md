# ProxySwitch

macOS 菜单栏小工具：**连上手机热点时自动开启 HTTP/HTTPS 代理，离开时自动关闭。**

## 背景

手机开热点、Clash 开启「允许来自局域网的连接」后，电脑可以直接把系统代理指向手机热点网关的 Clash 端口（例如 `10.23.216.132:7890`）。手动切换太麻烦，这个工具负责自动完成。

## 功能

- **事件驱动**：基于 `SCDynamicStore` 监听系统网络配置变化，不做轮询
- **自动开/关代理**：本机 IP 落在指定网段（默认 `10.23.216.`）时自动设置系统代理，离开即恢复直连
- **手动控制**：菜单里可单独「手动开代理 / 手动关代理」，手动关闭后不会被自动重开
- **切换 Wi-Fi**：列出已保存网络；系统不允许脚本切换时会提示改用系统菜单
- **设置面板**：热点名、代理服务器、端口、网段前缀、网络服务名、连接等待时间、菜单栏图标、SOCKS 端口等
- 菜单与设置窗口状态双向同步

## 构建

需要 macOS 13+ 和 Xcode Command Line Tools。

```bash
./build.sh
open ProxySwitch.app
```

首次运行后建议把 `ProxySwitch.app` 拖进「应用程序」，并在 系统设置 → 通用 → 登录项 中添加到开机启动。

## 使用

1. 菜单栏出现钥匙图标
2. 「自动检测：开」时，连上设定的热点会自动建立代理；断开或换网会自动释放
3. 点「设置…」可修改全部参数

## 已知限制

- `networksetup -setairportnetwork` 在部分 macOS 版本会返回 `-3900`，系统拒绝脚本直接切换 Wi-Fi。此时请用系统菜单栏的 Wi-Fi 手动切换，工具会自动识别并接管代理。
- 判断依据是本机 IP 网段，不是 SSID（无需定位权限，也更可靠）。
